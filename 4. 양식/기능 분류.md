# 1. 기능별 문서 분류
## 01. 고객앱
고객이 상품을 탐색하고 주문하는 영역
- 회원·로그인·주소 관리
- 상품·카테고리·검색
- 장바구니·옵션·구매 제한
- 주문서·결제·쿠폰
- 주문 내역·배송 조회·알림
- 고객센터·교환·환불

## 02. 물류센터 운영
상품이 센터에 입고되어 출고 준비를 마치는 영역
- 상품 마스터·SKU·바코드
- 입고 예정·검수·입고 확정
- 로트·소비기한·유통기한 관리
- 재고·보관 위치·재고 이동
- 피킹 작업·PDA
- 패킹·출고 검수·출고 확정
- 재고 실사·폐기·손실 처리

## 03. 배송·라이더앱
출고된 주문을 고객에게 전달하는 영역
- 배송 권역·배송 가능 여부
- 물류센터·배송거점 매칭
- 배송 작업 생성·배정
- 라이더 배차·수락·거절
- 픽업·배송 시작·완료
- 위치·배송 상태·고객 알림
- 배송 실패·오배송·재배송

## 04. 백오피스·운영
관리자가 상품과 현장 운영을 관리하는 영역
- 상품·가격·판매 상태 관리
- 센터·배송 권역·운영 설정
- 주문·결제·취소 관리
- 재고·입출고·피킹·패킹 현황
- 배송·라이더 현황
- 장애·예외·미처리 업무 관리
- 운영 대시보드·권한·작업 이력

## 05. 공통 업무 규칙
여러 기능에서 동일하게 적용해야 하는 규칙
- 주문·결제·취소 상태와 상태 전이
- 동시성·부분 실패·보상 처리
- 재처리·백업·데이터 정합성
- 알림 발송 조건
- 권한·접근 제어·감사 이력
- 외부 시스템 연동·장애 처리

# 2. 예시

## 고객앱

### F-001. 회원·로그인·주소 관리
	계정, 인증, 배송지 등록·변경, 기본 배송지
### F-002. 상품·카테고리·검색
	상품 조회, 판매 상태, 검색, 정렬, 필터
### F-003. 장바구니
	상품 추가·삭제, 수량, 옵션, 재고·가격 변경, 장바구니 동기화
### F-004. 주문서·결제
	주문 정보 확인, 쿠폰, 최종 금액 검증, 결제 요청 및 결과 처리
### F-005. 주문 내역·배송 조회·알림
	주문 상태, 배송 상태, 주문별 알림 및 조회
### F-006. 고객센터·교환·환불
	문의 접수, 교환·환불 신청, 처리 상태, 결과 안내

---

## 물류센터 운영
### F-007. 상품 마스터·SKU·바코드 관리
    상품 식별 정보, SKU 등록, 바코드 발급·매핑
### F-008. 입고 예정·입고 접수
    입고 예정 등록, 납품 정보 확인, 입고 작업 생성
### F-009. 입고 검수·입고 확정
    수량·품질 검수, 불량·초과·부족 입고 처리, 입고 확정
### F-010. 로트·소비기한 관리
    로트 식별, 제조일자·소비기한 관리, 로트별 재고 추적
### F-011. 재고·보관 위치 관리
    재고 수량, 가용 재고, 보관 위치, 적치·이동 관리
### F-012. 피킹 작업·PDA
    피킹 작업 생성, 작업자 할당, 상품 위치 안내, 피킹 결과 등록
### F-013. 패킹·출고 검수
    주문별 상품 포장, 구성품 확인, 오피킹·누락 검수
### F-014. 출고 확정·출고 인계
    출고 수량 확정, 재고 출고 반영, 배송 담당자 또는 거점 인계
### F-015. 재고 실사·조정
    장부 재고와 실물 재고 비교, 차이 확인, 재고 조정
### F-016. 폐기·손실 처리
    소비기한 경과, 파손, 품질 이상, 분실에 따른 재고 차감

---

## 배송·라이더앱
### F-017. 배송 권역·배송 가능 여부
    배송 권역 설정, 주소별 배송 가능 여부, 운영 시간·제한 조건
### F-018. 물류센터·배송거점 매칭
    배송지 기준 센터 선정, 배송거점 경유 여부, 처리 가능 센터 결정
### F-019. 배송 작업 생성·배정
    출고 주문 기반 배송 작업 생성, 배송 묶음 구성, 담당자 배정
### F-020. 라이더 배차·수락·거절
    라이더 후보 조회, 배차 요청, 수락·거절, 배차 재시도
### F-021. 픽업·배송 수행
    센터·거점 도착, 상품 인수 확인, 배송 시작, 배송 완료 처리
### F-022. 위치·배송 상태·고객 알림
    라이더 위치 정보, 배송 진행 상태, 도착 예정 정보, 고객 알림 연계
### F-023. 배송 실패·오배송·재배송
    고객 부재, 주소 오류, 상품 오인도, 배송 실패 기록, 재배송 처리

---

## 백오피스·운영
### F-024. 상품·가격·판매 상태 관리
    상품 등록·수정, 판매가 변경, 판매 중지·재개, 노출 관리
### F-025. 센터·배송 권역·운영 설정
    센터·거점 정보, 운영 시간, 배송 권역, 처리 가능 조건 설정
### F-026. 주문·결제·취소 관리
    주문 조회, 결제 결과 확인, 주문 취소 요청, 운영자 조치
### F-027. 재고·입출고 현황 관리
    센터별 재고 조회, 입고·출고 현황, 재고 부족·불일치 확인
### F-028. 피킹·패킹 작업 현황 관리
    작업 진행률, 작업 지연, 미처리 작업, 작업 재배정
### F-029. 배송·라이더 현황 관리
    배송 작업 현황, 배차 상태, 지연 배송, 배송 실패 확인
### F-030. 장애·예외·미처리 업무 관리
    업무 오류 조회, 예외 건 할당, 담당자 지정, 해결 상태 관리
### F-031. 운영 대시보드·지표 관리
    주문량, 처리 시간, 재고 현황, 배송 지연, 미처리 업무 지표
### F-032. 운영자 권한·작업 이력 관리
    운영자 역할, 기능별 접근 권한, 주요 변경 이력, 조작 기록

---

## 공통 업무 규칙
### F-033. 업무 상태·상태 전이·취소 규칙
    주문·결제·입고·피킹·패킹·배송 상태, 상태 변경 조건, 취소 가능 조건
### F-034. 동시성·부분 실패·보상 처리
    중복 요청, 동시 재고 차감, 일부 단계 실패, 트랜잭션 및 보상 처리
### F-035. 재처리·백업·데이터 복구·정합성
    실패 작업 재처리, 중복 처리 방지, 데이터 백업·복구, 시스템 간 데이터 비교
### F-036. 알림 발송 규칙
    알림 발송 조건, 발송 시점, 대상자, 중복 발송 방지, 실패 재시도
### F-037. 권한·접근 제어·감사 이력 규칙
    역할별 접근 범위, 업무별 실행 권한, 민감 정보 접근, 감사 로그 기록 기준
### F-038. 외부 시스템 연동·장애 처리
    결제·알림·지도·외부 물류 시스템 연동, 요청·응답 규격, 타임아웃, 장애 대응
