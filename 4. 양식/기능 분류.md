# 1. 기능별 문서 분류
## 01. 고객앱
고객이 상품을 탐색하고 주문하는 영역
- 회원·로그인·주소 관리
- 상품·카테고리·검색
- 장바구니·옵션·구매 제한
- 주문서·결제·쿠폰
- 주문 내역·배송 조회·알림
- 고객센터·교환·환불

## 02. 물류센터 운영
상품이 센터에 입고되어 출고 준비를 마치는 영역
- 상품 마스터·SKU·바코드
- 입고 예정·검수·입고 확정
- 로트·소비기한·유통기한 관리
- 재고·보관 위치·재고 이동
- 피킹 작업·PDA
- 패킹·출고 검수·출고 확정
- 재고 실사·폐기·손실 처리

## 03. 배송·라이더앱
출고된 주문을 고객에게 전달하는 영역
- 배송 권역·배송 가능 여부
- 물류센터·배송거점 매칭
- 배송 작업 생성·배정
- 라이더 배차·수락·거절
- 픽업·배송 시작·완료
- 위치·배송 상태·고객 알림
- 배송 실패·오배송·재배송

## 04. 백오피스·운영
관리자가 상품과 현장 운영을 관리하는 영역
- 상품·가격·판매 상태 관리
- 센터·배송 권역·운영 설정
- 주문·결제·취소 관리
- 재고·입출고·피킹·패킹 현황
- 배송·라이더 현황
- 장애·예외·미처리 업무 관리
- 운영 대시보드·권한·작업 이력

## 05. 공통 업무 규칙
여러 기능에서 동일하게 적용해야 하는 규칙
- 주문·결제·취소 상태와 상태 전이
- 동시성·부분 실패·보상 처리
- 재처리·백업·데이터 정합성
- 알림 발송 조건
- 권한·접근 제어·감사 이력
- 외부 시스템 연동·장애 처리

# 2. 예시

## 고객앱

### F-001. 회원·로그인·주소 관리
	계정, 인증, 배송지 등록·변경, 기본 배송지
### F-002. 상품·카테고리·검색
	상품 조회, 판매 상태, 검색, 정렬, 필터
### F-003. 장바구니
	상품 추가·삭제, 수량, 옵션, 재고·가격 변경, 장바구니 동기화
### F-004. 주문서·결제
	주문 정보 확인, 쿠폰, 최종 금액 검증, 결제 요청 및 결과 처리
### F-005. 주문 내역·배송 조회·알림
	주문 상태, 배송 상태, 주문별 알림 및 조회
### F-006. 고객센터·교환·환불
	문의 접수, 교환·환불 신청, 처리 상태, 결과 안내
