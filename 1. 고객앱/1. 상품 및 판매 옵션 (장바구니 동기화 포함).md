# 2. 판매 옵션 및 수량 선택

**기획 목적:** 하나의 상품에 여러 판매 옵션을 등록하고, 각 옵션의 가격과 재고를 독립적으로 관리할 수 있도록 한다.
❓ B마트에는 옵션이 없는 것 같음

## 2.1 판매 옵션 구성

- 🗄️ 상품 기본 정보
  - 🔑 상품 코드: P1001
  - 🔑 상품명
  - 🔑 상품 유형
- 🗄️ 옵션 정보
  - 🔑 옵션 코드
  - 🔑 옵션명
  - 🔑 판매 단위
  - 🔑 가격
  - 🔑 재고
  - 🔑 판매 상태: 판매 중 / 품절 / 판매 중지

## 2.2 판매 옵션 예시

| 옵션 코드 | 옵션명 | 판매 단위 | 가격 예시 | 재고 예시 | 판매 상태 |
|---|---|---:|---:|---:|---|
| U1 | 낱병 (1병) | 1병 | 2,000원 | 100병 | 판매 중 |
| U6 | 6병 묶음 | 6병 | 10,000원 | 2,300묶음 | 판매 중 |

※ 가격과 재고는 기획 예시이며 실제 운영 정책에 따라 결정한다. 재고는 옵션별 판매 가능 수량을 기준으로 관리한다.

실물 수량과 비교 예시:

| 선택 옵션 | 선택 수량 | 실물 수량 | 상품 금액 |
|---|---:|---:|---:|
| 낱병 | 2개 | 2병 | 4,000원 |
| 6병 묶음 | 2개 | 12병 | 20,000원 |

## 2.3 ⚙️ 옵션 선택 규칙

- 장바구니에 담기 전에 판매 옵션을 선택한다.
- 옵션별로 가격, 판매 단위 및 재고를 확인한다.
- 품절 또는 판매 중지 옵션은 선택할 수 없도록 한다.
- ❓ 옵션을 변경할 때 수량을 초기화할지 유지할지 결정한다. (금액 재계산 필수)
- 선택한 옵션의 판매 단위에 따라 총금액과 실물 수량을 계산한다.
- 판매 단위가 다른 옵션은 고객이 구성 수량을 명확하게 이해할 수 있도록 표시한다.

## 2.4. ⚙️ 수량 정의

**핵심 원칙:** 고객이 선택하는 옵션 수량과 실제 상품 개수를 구분한다.

| 구분 | 의미 | 예시 |
|---|---|---|
| 판매 단위 | 옵션 1개에 포함된 실물 수량 | 6병 |
| 선택 수량 | 고객이 선택한 옵션 개수 | 2개 |
| 실물 수량 | 실제 상품의 총개수 | 12병 |
| 옵션 단가 | 옵션 1개당 가격 | 10,000원 |
| 상품 금액 | 옵션 단가 × 선택 수량 | 20,000원 |

## 2.5 ⚙️ 화면 표시 원칙

- 옵션명에 판매 단위를 표시한다.
- 장바구니에서는 옵션 수량과 실물 수량을 구분해 표시한다.
- 단위 가격은 상품 유형에 맞게 표시한다.
- 옵션 변경 시 선택 수량, 실물 수량 및 금액을 다시 계산한다.
- 구매 한도가 적용되는 기준 단위를 고객이 이해할 수 있도록 안내한다.

## 3.1. 상품 및 옵션 데이터 구성

**핵심 정보:** 상품과 판매 옵션은 별도로 관리하며, 장바구니에는 고객이 선택한 옵션을 기준으로 저장한다.

### 3.1.1 🗄️ 상품 정보

- 🔑 상품 코드: P1001
- 🔑 상품명
- 🔑 상품 유형

- 🔑 판매 옵션 및 수량
  - 품절 및 판매 중지 상태

### 3.1.2 🗄️ 옵션 정보

- 🔑 옵션 코드: U1, U6 등
- 🔑 옵션명: 낱병(1병), 6병 묶음(6병)
- 🔑 판매 단위: 1병, 6병
- 🔑 판매 가격
- 🔑 재고
- 🔑 판매 상태

## 3.2. 장바구니 데이터 (다른 파일에 자세히)

장바구니에는 상품 코드뿐 아니라 옵션 코드, 선택 수량 및 주문 당시 필요한 가격 정보를 연결한다.

### 3.2.1 장바구니 저장 정보

| 항목 | 예시 | 설명 |
|---|---|---|
| 상품 코드 | P1001 | 상품 식별 |
| 옵션 코드 | U6 | 선택한 판매 옵션 |
| 선택 수량 | 2 | 6병 묶음 2개 |
| 판매 단위 | 6병 | 옵션 1개당 실물 수량 |
| 실물 수량 | 12병 | 6병 × 2개 |
| 옵션 단가 | 10,000원 | 묶음 1개당 가격 |
| 상품 금액 | 20,000원 | 옵션 단가 × 선택 수량 |

※ 상품 금액은 쿠폰 적용 전 금액으로 정의한다. 상품 할인과 쿠폰 할인은 별도 항목으로 관리한다.

### 3.2.2 수량 및 금액 계산

「2.4. ⚙️ 수량 정의」참고

- 선택 수량 = 고객이 장바구니에 담은 옵션 개수
- 실물 수량 = 판매 단위 × 선택 수량
- 상품 금액 = 옵션 단가 × 선택 수량

예시:

- 1병 옵션 2개 선택 → 실물 수량 2병, 상품 금액 4,000원
- 6병 묶음 옵션 2개 선택 → 실물 수량 12병, 상품 금액 20,000원

## 3.3 ⚙️ 판매 옵션 중지와 기존 장바구니 처리

# 4. 구매 제한 및 재고 검증

**기획 목적:** 구매 한도와 재고를 확인해 구매할 수 없는 상품이 장바구니에 추가되거나 결제되지 않도록 한다.

## 4.1 ⚙️ 구매 한도

- 상품 또는 옵션별 구매 가능 수량을 검증한다.
- 구매 한도를 초과하는 수량 증가를 제한한다.
- 최대 수량에 도달하면 수량을 유지하고 안내 메시지를 표시한다.

💬 [구매 한도로 더 이상 추가할 수 없습니다. (최대 3병)]

## 4.2 재고 부족 및 품절

- 상품 상세 조회 시 판매 가능 여부를 표시한다.
- 장바구니 담기 직전에 재고와 판매 상태를 재확인한다.
- 결제 진행 전에도 구매 가능 수량을 검증한다.
- 재고가 부족하거나 품절된 경우 장바구니 추가 및 구매를 제한한다.
- 담기 실패 시 안내 메시지를 표시한다.
- 품절 안내 후 상품 상세 화면에서 구매 불가 상태를 확인할 수 있도록 한다.

💬 [품절되어 추가할 수 없습니다. 해당 상품은 현재 품절되었습니다. 다른 상품을 이용해 주세요.]

💬 [재고 상황에 따라 상품이 조기 품절될 수 있습니다.]

## 4.3 ⚙️ 장바구니 및 주문 상태별 처리

운영자가 특정 옵션의 판매를 중지하더라도 "기존 장바구니"와 "주문 이력"을 구분하여 처리한다.

- 장바구니에 담긴 상품은 삭제하지 않고 구매 불가 상태로 표시한다.
- 판매 중지 옵션은 추가 구매 및 결제를 제한한다.
- 고객은 해당 옵션(구매 불가 상품)을 장바구니에서 삭제할 수 있다.
- 이미 생성된 주문은 주문 당시의 상품명, 옵션명, 판매 단위, 가격 및 주문 금액을 보존한다.
- 상품 옵션(판매 옵션)의 현재 판매 상태가 변경되더라도 과거 주문 내역은 변경하지 않는다.

※ 주문이 이미 생성된 경우와 장바구니에만 담긴 경우는 서로 다른 정책으로 처리한다.

| 담기 직전 품절 | 장바구니 추가 실패 및 안내 |
| 옵션 판매 중지 | 구매 불가 표시 |
| 장바구니 수량 변경 | 수량 및 금액 재계산 |

### 6.1 상품 목록 및 상세 조회

- [ ] 상품 목록 조회 성공 시 상품 이미지, 상품명, 가격 등 기본 정보가 표시되는지 확인
- [ ] 상품 선택 시 해당 상품의 상세 화면으로 이동하는지 확인
- [ ] 상품 상세에서 뒤로 가기 시 기존 검색 조건과 검색 결과가 유지되는지 확인
- [ ] 평점 및 리뷰 영역 선택 시 리뷰 화면으로 이동하는지 확인
- [ ] 상품 정보 조회 중 로딩 상태가 표시되는지 확인
- [ ] 상품 정보 조회 실패 시 오류 안내 및 재시도 기능이 제공되는지 확인
- [ ] 품절 및 판매 중지 상태가 상품 상세에 표시되는지 확인

### 6.2 판매 옵션 및 수량 계산

- [ ] 판매 중인 옵션 선택 시 해당 옵션의 가격, 판매 단위 및 재고가 표시되는지 확인
- [ ] 낱병 옵션 2개 선택 시 실물 수량 2병, 상품 금액 4,000원으로 계산되는지 확인
- [ ] 6병 묶음 옵션 2개 선택 시 실물 수량 12병, 상품 금액 20,000원으로 계산되는지 확인
- [ ] 옵션 변경 시 선택 수량, 실물 수량 및 상품 금액이 올바르게 재계산되는지 확인
- [ ] 품절 또는 판매 중지 옵션을 선택할 수 없는지 확인
- [ ] 옵션별 판매 가능 재고를 기준으로 수량이 검증되는지 확인

### 6.3 장바구니 담기 및 수량 동기화

- [ ] 상품 상세에서 선택한 상품 및 옵션 정보가 장바구니에 정확하게 저장되는지 확인
- [ ] 장바구니에서 선택 수량과 실물 수량이 구분되어 표시되는지 확인
- [ ] 장바구니 수량 변경 시 실물 수량과 상품 금액이 재계산되는지 확인
- [ ] 상품 할인 금액과 쿠폰 할인 금액이 별도로 관리되는지 확인
- [ ] 장바구니에 저장된 옵션 코드가 실제 선택한 옵션과 일치하는지 확인
- [ ] 장바구니 담기 요청 중 통신 오류 발생 시 중복 담기가 발생하지 않는지 확인

### 6.4 구매 한도 및 재고 검증

- [ ] 구매 한도 이내에서 수량을 정상적으로 증가할 수 있는지 확인
- [ ] 구매 한도 도달 시 추가 수량 증가가 제한되고 안내 메시지가 표시되는지 확인
- [ ] 재고보다 많은 수량을 구매할 수 없도록 제한되는지 확인
- [ ] 상품 상세 조회 후 재고가 감소한 경우 장바구니 담기 시 최신 재고를 재검증하는지 확인
- [ ] 장바구니 담기 직전에 품절된 경우 상품이 추가되지 않고 안내 메시지가 표시되는지 확인
- [ ] 장바구니 담기 직전에 재고가 부족해진 경우 구매가 제한되는지 확인
- [ ] 결제 진행 전 최신 재고 및 구매 가능 수량을 재검증하는지 확인
- [ ] 결제 직전에 최신 가격을 재조회하고 최종 결제 금액에 반영하는지 확인
- [ ] 가격 변경 시 변경된 금액이 고객에게 안내되는지 확인

### 6.5 판매 옵션 중지 및 기존 주문 처리

- [ ] 장바구니에 담긴 옵션이 판매 중지되어도 장바구니 항목이 유지되는지 확인
- [ ] 판매 중지된 옵션에 구매 불가 상태가 표시되는지 확인
- [ ] 판매 중지된 옵션을 추가 구매하거나 결제할 수 없는지 확인
- [ ] 고객이 구매 불가 상태의 장바구니 항목을 직접 삭제할 수 있는지 확인
- [ ] 주문 생성 후 상품명이나 옵션 정보가 변경되어도 기존 주문 정보가 유지되는지 확인
- [ ] 주문 생성 후 가격이 변경되어도 기존 주문의 주문 당시 가격과 금액이 유지되는지 확인
- [ ] 판매 옵션의 현재 상태가 변경되어도 과거 주문 내역이 변경되지 않는지 확인

### 6.6 로딩, 빈 결과 및 오류 처리

- [ ] 상품 정보 조회 시작 시 로딩 상태가 표시되는지 확인
- [ ] 조회 성공 후 결과가 0건이면 오류가 아닌 빈 결과 화면이 표시되는지 확인
- [ ] 조회 성공 후 상품 2개가 반환되면 상품 2개가 정상적으로 표시되는지 확인
- [ ] 네트워크 오류 발생 시 오류 안내 및 재시도 기능이 제공되는지 확인
- [ ] 재시도 후에도 검색 조건과 사용자가 입력한 정보가 유지되는지 확인
- [ ] 이전 요청의 응답이 늦게 도착해도 최신 요청의 결과를 덮어쓰지 않는지 확인
- [ ] 오류 발생 후 정의된 정책에 따라 현재 화면 유지 또는 이전 화면 복귀가 이루어지는지 확인

### 6.7 접근성 및 화면 표시

- [ ] 큰 글자 모드에서 상품 정보, 가격, 수량 조절 버튼 및 주요 안내 문구가 잘리지 않는지 확인
- [ ] 품절 및 판매 중지 상태가 색상뿐 아니라 텍스트로 구분되는지 확인
- [ ] 비활성화된 버튼의 상태와 사유를 스크린리더로 확인할 수 있는지 확인
- [ ] 로딩 시작 시 스크린리더가 로딩 상태를 안내하는지 확인
- [ ] 조회 성공 시 빈 결과 또는 상품 목록 개수를 스크린리더로 안내하는지 확인
- [ ] 네트워크 오류 발생 시 스크린리더로 오류 메시지를 확인할 수 있는지 확인
- [ ] 입력 오류 발생 시 오류 메시지가 표시되고 필요한 경우 해당 입력 필드로 초점이 이동하는지 확인
- [ ] 버튼의 이름과 기능이 스크린리더로 안내되는지 확인
