# 1. 배송 방식 및 배송 정보

## 1.1 배송 방식 선택

장바구니에서 배송 방식을 선택하고, 예약배달을 선택한 경우 원하는 도착 시간대를 지정한다.

- 배송 방식은 다음 중 하나를 선택한다.
  - 한집배달
  - 알뜰배달
  - 예약배달
- 한집배달 및 알뜰배달은 예상 배송 시간을 안내한다.
- 예약배달은 고객이 원하는 도착 시간대를 선택한다.
- **밤 12시부터 오전 8시까지는 예약배달만 가능하다.**

## 1.2 배송 및 배달 정보

- 예상 배송 시간: `00~00분 후 도착`
- 예약배달 도착 시간: 오늘 또는 내일의 시간대 선택
- 최소 주문 금액: 15,000원
- 배달팁 및 무료 배달 조건
- 배송 방식별 요금

※ ❓ 결정 필요
- 최소 주문 금액, 배달팁, 무료 배달 조건 및 배송 방식별 요금의 적용 기준
- 지역·시간·프로모션에 따른 요금 및 예약 가능 시간의 차등 적용 여부

# 2. 배송 시간 선택 흐름

🔗 장바구니 → 배송 방식 선택 → 배송 시간 선택 → 시간 선택 팝업 → 선택 완료

## 2.1 배송 시간 선택하기

- 예약배달 선택 시 도착 시간대 선택 기능을 제공한다.
- 배송 가능 시간, 선택 조건 및 대상 지역을 기준으로 선택 가능한 시간대를 조회한다.
- 선택 가능한 날짜와 시간대를 표시한다.
  - 날짜: 오늘, 내일
  - 시간대: 1시간 단위

## 2.2 시간 선택 임시 상태

- 시간 선택 팝업에서 원하는 시간대를 선택한다.
- 선택 완료 전에는 다른 시간대로 변경할 수 있다.
- 선택 취소 시 기존 화면으로 돌아간다.
- 선택 완료 시 선택 결과를 장바구니에 반영한다.

※ ❓ 결정 필요
- 임시 선택 상태의 유지 기간
- 시간대를 선택한 시점에 예약을 확보할지 여부

## 2.3 배송 시간 선택 완료

- 선택한 날짜와 시간대를 장바구니에 표시한다.
- 주문서 진입 및 결제 진행 시 선택한 시간대의 유효 여부를 재검증한다.
- 배송지 변경이나 시간대 마감 등으로 기존 선택이 유효하지 않으면 재선택을 안내한다.

# 3. 배송 가능 시간 및 마감 정책

## 3.1 ⚙️ 배송 가능 시간 기준

- 배송 대상 지역에 따라 선택 가능한 날짜와 시간대를 제공한다.
- 예약배달은 1시간 단위로 도착 시간대를 선택한다.
- **밤 12시부터 오전 8시까지는 예약배달만 가능하다.**
- 예약 주문 시간 마감은 해당 시간대에 포함되는 시점으로 정의되어 있다.

※ 결정 필요
- 지역별 배송 가능 시간 및 선택 조건
- 예약배달의 정확한 시작·종료 시간과 시간대 표기 기준
- 시간대 마감 시점의 정확한 기준
- 동래구와 부산진구의 배송 시간 정책 동일 적용 여부

## 3.2 특정 시간대 마감

- 특정 시간대가 마감되면 해당 시간대를 선택할 수 없도록 처리한다.
- 다른 이용 가능한 시간대를 표시한다.
- 이미 선택한 시간대가 마감된 경우 재선택을 안내한다.

💬 안내 문구 예시

> 선택하신 배송 시간은 마감되었습니다. 다른 시간을 선택해주세요.

## 3.3 모든 시간대 마감

- 선택 가능한 시간대가 없는 경우 안내 메시지를 표시한다.
- 배송 시간 선택을 확정할 수 없도록 처리한다.
- 재조회 또는 다음 이용 가능 시간 안내 여부는 정책에 따라 결정한다.

💬 안내 문구 예시

> 현재 선택 가능한 배송 시간이 없습니다. 잠시 후 다시 확인해주세요.

## 3.4 배송 시간 조회 오류

- 네트워크 또는 서버 오류로 배송 시간대를 조회하지 못한 경우 오류 안내를 표시한다.
- 조회에 실패한 시간대를 유효한 배송 시간으로 확정하지 않는다.
- 재조회 기능을 제공한다.

💬 안내 문구 예시

> 배송 가능 시간을 불러오지 못했어요. 잠시 후 다시 시도해주세요.

※ ❓ 결정 필요
- 조회 오류 시 자동 재시도 적용 여부
- 이전에 조회한 시간대를 임시로 표시할지 여부
- 조회 오류 상태에서 주문 진행을 허용할지 여부

# 4. 주문서 및 결제 단계 연계

- 주문서 진입 시 선택한 배송 시간대의 유효 여부를 확인한다.
- 배송지 변경 시 변경된 지역의 배송 가능 시간대를 다시 확인한다.
- 결제 요청 전 배송 시간대의 유효 여부를 검증한다.
- 주문 진행 중 선택한 시간대가 마감된 경우 재선택 등 후속 처리를 적용한다.

※ ❓ 결정 필요
- 주문서 진입 후 시간대가 마감된 경우의 처리 방식
- 결제 요청 전 시간대가 마감된 경우 결제 진행 제한 여부
- 배송 시간 변경 시 배달팁 및 주문 금액 재검증 여부

- [ ] 배송지 변경 시 변경된 지역의 배송 가능 시간대를 다시 확인하는지 확인
- [ ] 주문서 진입 및 결제 진행 시 선택한 시간대의 유효 여부를 검증하는지 확인
- [ ] 최소 주문 금액 및 배송 방식별 요금이 정의된 정책에 따라 적용되는지 확인
