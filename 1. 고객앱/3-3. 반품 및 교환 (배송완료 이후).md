# 2. 교환 신청

## 2.1 교환 신청 조건

- 배송 완료 이후 교환 신청을 지원한다.
- 상온 제품은 단순 변심·실수로 인한 교환을 허용한다.
- 냉장·냉동 식품은 단순 변심·실수로 인한 교환을 제한한다.
- 신선보장 제품은 신선하지 않은 경우 교환을 허용한다.

※ ❓ 결정 필요
- 냉장·냉동 식품의 상품문제 및 배달 문제로 인한 교환 허용 범위
- 신선보장 제품의 교환 신청 가능 기간 및 판단 기준

## 2.2 교환 상품 선택

- 교환 신청 시 해당 주문에 포함된 품목 중 교환할 상품을 선택한다.
- 전체 선택 버튼을 제공한다.

## 2.3 교환 이유 선택

교환 이유는 `변심·실수`, `상품문제`, `배달 문제`로 구분한다.

### 2.3.1 변심·실수

- 상품이 마음에 들지 않아요
- 상품을 잘못 주문했어요
- 주소를 잘못 설정했어요

- 상세 이유: 선택 사항
- 사진 첨부: 선택 사항

### 2.3.2 상품문제

- 상품이 설명과 달라요
- 상품의 기능에 문제가 있어요
- 식품이 변질됐어요
- 상품에 이물질이 발견됐어요
- 상품의 유통/소비기한이 지났어요

- 상세 이유: 필수
- 사진 첨부: 필수

### 2.3.3 배달 문제

- 상품이 파손되어 배달됐어요
- 일부 다른 상품이 배달됐어요
- 모두 다른 상품이 배달됐어요
- 주문한 상품 중 일부는 배달이 안 왔어요
- 배달완료인데 아직 배달이 안 왔어요

- 상세 이유: 필수
- 사진 첨부: 필수

## 2.4 교환 방법 선택

- 교환 방법은 `라이더가 회수·재배달` 방식으로 제공한다.
- 라이더가 기존 상품을 회수하고 교환 상품을 재배달한다.

### 2.4.1 배달팁

- 교환 이유가 `변심·실수`인 경우 배달팁은 9,000원으로 설정한다.
- 교환 이유가 `상품문제` 또는 `배달 문제`인 경우 배달팁은 무료로 설정한다.
- 교환 이유에 따라 배달팁이 자동 적용된다.

### 2.4.2 회수지 정보

- 회수지 정보는 기존 정보를 그대로 사용한다.

### 2.4.3 라이더 요청 사항

- 회수할 때의 라이더 요청 사항을 설정한다.
- 재배달할 때의 라이더 요청 사항을 설정한다.
- 회수와 재배달 요청 사항은 각각 별도로 설정한다.

※ ❓ 결정 필요
- 교환 상품 선택 시 전체 선택과 개별 선택의 동작 기준
- 여러 상품을 선택한 경우 교환 이유를 상품별로 설정할지, 신청 전체에 공통 적용할지 결정
  - B마트는 신청 전체 공통 적용
- 변심·실수 교환 시 배달팁 9,000원의 적용 단위 및 결제 방식
- 회수지 정보 변경을 허용할지 결정
- 회수 및 재배달 요청 사항의 입력 방식과 글자 수 제한
- 교환 상품의 재고 부족 또는 재배달 불가 시 처리 방식
